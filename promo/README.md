# Promo film: source and re-rendering

`assets/xidid-promo.mp4` (and its `.webm` fallback) is rendered from
`stage.html`, a 1920×1080 page whose every element is a pure function of
time (`render(t)`), using real screenshots of the app in `caps/`. No
footage is generated by AI, and every number shown is real.

Re-render after the interface changes (all commands from the project root):

```sh
# Needs: Python 3 with Playwright (pip install playwright && playwright install chromium),
# ffmpeg, and the fonts Fraunces, Work Sans and IBM Plex Mono installed locally
# (from fonts.google.com) so the captures and the film use the brand type.

python3 -m http.server 8765 &                  # the app
python3 promo/capture.py                       # 1. real UI captures -> promo/caps/
kill %1

(cd promo && python3 -m http.server 8766) &    # the stage
mkdir -p promo/frames
python3 promo/render.py 0 900                  # 2. 900 frames (30 s at 30 fps), ~4 min
kill %1

# 3. encode
ffmpeg -y -framerate 30 -i promo/frames/f%04d.png -c:v libx264 -preset slow -crf 22 \
  -pix_fmt yuv420p -movflags +faststart -an assets/xidid-promo.mp4
ffmpeg -y -framerate 30 -i promo/frames/f%04d.png -c:v libvpx-vp9 -b:v 0 -crf 34 \
  -row-mt 1 -pix_fmt yuv420p -an assets/xidid-promo.webm
ffmpeg -y -ss 27.5 -i assets/xidid-promo.mp4 -frames:v 1 -q:v 3 assets/xidid-promo-poster.jpg
```

To preview a moment without rendering everything, open
`http://localhost:8766/stage.html` and run `render(14.5)` in the console.
Highlight boxes in the explanation shot are positioned from measured
pixel rows of `caps/explain.png`; re-measure them if that capture changes.
